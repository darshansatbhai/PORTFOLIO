## 📋 How to Record the Video

### Option 1: OBS Studio (Best Quality)
1. Open `D:\PORTFOLIO\port\public\launch-video.html` in Chrome
2. Open OBS Studio → Add "Window Capture" → Select Chrome
3. Set canvas to 1080x1920 (vertical)
4. Hit Record → Refresh the HTML page → Wait 28 seconds → Stop
5. Export as MP4

### Option 2: Chrome DevTools Screen Record
1. Open the HTML file in Chrome
2. Press F12 → Performance tab → Click Record ⏺️
3. Refresh the page → Wait 28 seconds → Stop recording
4. Right-click → Save as...

### Option 3: Xbox Game Bar (Windows)
1. Open HTML in Chrome (fullscreen F11)
2. Press Win + G → Click Record
3. Wait 28 seconds → Stop
4. Find recording in Videos\Captures folder

### Option 4: Phone Screen Record
1. Open `www.daarshannexaa.in/launch-video.html` on your phone browser
2. Start screen recording from notification shade
3. Wait 28 seconds → Stop → Share directly to Instagram/X
